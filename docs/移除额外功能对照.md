# 移除安卓没有的额外功能

> 2026-11-04 真机更新：已按用户要求删除底部光标滑块/占位，并优化输入时的按键复用与读音查询。最新记录见 [真机输入修复](真机底部占位与输入流畅度修复.md)。
> 2026-11-04 更新：已删除此前自行设置的“闲置 5 分钟关闭”，一次开启后不再因闲置停止。当前会话边界及回归见 [语音持续会话修复](语音持续会话修复.md)。
日期：2026-11-03。依据：用户要求“检查对照一遍，安卓没有的去掉”。

## 对照依据与范围

- 安卓实际产品源码：`../LianAi-Keyboard`，提交 `212529fba1e2c4f49cb982564f6bd6ee870ab01a`，1.5.9（39）；本轮未修改安卓源码。
- 核对 `MainActivity.kt`、`ModelConfigurationViews.kt`、`SubscriptionViews.kt`、`WeikeKeyboardView.kt`、`WeikeInputMethodService.kt` 的当前入口和操作；完整基线见 [Android 功能基线](Android功能基线.md)。
- iOS 核对 `App` 全部页面、根弹窗与路由，以及 `Keyboard/KeyboardViewController.swift` 的模式、输入面板和操作。
- 按安卓**当前可达入口**对照；源码里遗留但当前没有入口的录音润色、指令工具、定制输入法设置，不作为新增 iOS 入口的依据。
- 本轮是额外功能清理，并不撤销此前记录的 iOS 平台限制，也不据此宣称全功能百分之百一致。

## 保留的明确要求和平台必要差异

- 用户已明确要求：支付宝支付；移除自绘底部地球/麦克风两个图标；空格文字后有麦克风图标；语音识别区在原键盘上方，按键不移动；松开结束。以上不因本轮清理恢复成旧版本。
- iOS 必需：系统启用/完全访问指引、首次 AI 内容授权、主 App 语音会话激活和关闭、系统选图与权限。它们服务于现有功能，不扩展新的产品工具或页面。
- 横屏全局浮窗、宿主包名自动文风、复制时间监听等既有平台差异仍见 [一致性验收](一致性验收.md)。

## 本轮验证

首轮全量运行：38 项基础逻辑通过；Xcode 中 14 项宿主集成通过，22 项 UI 中 21 项通过、1 项失败。失败是录音中离开试用页并重新打开键盘时，扩展在 `viewWillAppear` 读取了旧宿主的 `documentIdentifier`，崩溃栈为 `objc_msgSend → _UITextDocumentInterface.documentIdentifier → KeyboardDocumentContext.identifier → KeyboardViewController.viewWillAppear`。

已移除出现阶段的输入框标识读取，在页面接入后的输入回调或用户操作中绑定；离开前失效输入会话、取消语音和异步任务。原失败用例改为连续三次离开/重开，随完整回归重测。该修复不增加任何产品入口。首轮失败保留在 `.build-artifacts/AndroidOnlyFeatures.xcresult`，没有把它记作全通过。

最终版本全量回归已通过，**75 个不同用例，0 失败、0 跳过**。重复运行不累计计数。

| 检查 | 最终结果 |
| --- | --- |
| LianAiCore 基础逻辑 | 38 项通过 |
| 宿主集成 | 14 项通过 |
| 实际界面/键盘扩展 | 23 项通过：全部主页面、配置、登录校验、主题、中文/英文/符号/表情、AI 原按钮、实际选图、语音和权限 |
| 原崩溃路径 | 连续三次录音中离开并重开键盘，通过；不插入迟到结果 |

| Release arm64 | 构建通过；主程序和扩展均未残留已删除入口文案或 Debug fixture 标记 |
| 原模拟器更新 | 已安装并启动；6 个代码文件哈希与最终 Debug 构建一致，未卸载/清空原数据 |

最终结果包：`.build-artifacts/AndroidOnlyVerified.xcresult`（37 项，其中 14 宿主 + 23 UI）。基础逻辑日志及前后两轮日志位于 `.build-artifacts/android-only/logs`。结构化证据见 [android-only-results.json](android-only-results.json)。此前文档中针对已删除功能的通过记录仅保留为历史记录，不作为当前版本证据。

模拟器验收不等于线上 AI 或真实识别质量验收：AI/ASR 返回使用测试服务；原生音频专项实际经过系统权限、AVAudioEngine、后台主 App 和键盘扩展。没有进行真实付款、注册账号或签名真机测试，仍按用户确认的“先完成可运行版本和模拟器验收”执行。
