# AI 结果页安卓对齐验收（2026-11-19）

本轮范围：安卓保持现有版本，只调整 iOS「帮你回」「超会说」的 AI 结果展示和对应操作。

## 对照环境

- 安卓：现有 1.6.12（52）APK，Android 14 模拟器；未修改安卓代码。源码工作区原有未跟踪文档保持原样。
- iOS：iPhone 18 Pro / iOS 27 模拟器；主应用和键盘扩展一起运行。Release 使用现有公司证书签名构建通过。
- 使用用户提供的测试账号登录真实后端，两端原话均为 `Tomorrow can we have dinner?`，分别独立生成。因此返回文案不同，截图用于核对布局与操作。
- 测试原话由 Debug 主应用写入自身剪贴板，AI 请求使用真实账号和真实服务；未启用模拟 AI 返回。账号密码不写入源码或截图包。

| 项目 | 对齐结果 |

| 超会说九宫格 | 无拼音组合时底部显示安卓原有的粘贴键；有组合时恢复选拼音；粘贴仅写入优化草稿 |

## 验证结果

分组完成 51 个相关测试（包含下述 5 个 UI 用例），均通过；没有将其描述为全 App 回归。

- LianAiCore：44 项，包括账号路由、官方/自定义模型、知识库资料加载与请求内容。
- UIKit 结果面板：2 项，验证长文不缩字、完整选择文本、点击回调，以及紧凑深色布局按钮无重叠。
- UI 自动化：帮你回生成中关闭/长文三条结果、粘贴/截图入口与重新分析和关闭、超会说写新内容、知识库选择作废旧结果、真实账号生成与选择替换。
- 真实账号用例：帮你回、超会说均返回三条；选择另一条确实替换；超会说粘贴只进入草稿；写新内容保留宿主已填入文本。
- Release 主应用与扩展签名构建通过；git diff --check 通过。

最初批跑曾遇到模拟器焦点恢复、外部测试程序剪贴板授权和测试脚本查找不存在的粘贴入口问题；已调整焦点操作、在主应用准备测试原话，并对齐安卓九宫格粘贴入口后重测通过。本轮真实交互在模拟器完成，未以真机验证替代这些记录。
