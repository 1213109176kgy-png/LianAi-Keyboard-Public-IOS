已按用户要求将整块语音覆盖面板改为键盘上方的识别条。保留原按键对象与长按手势，锁定按键区尺寸并固定在底部，识别区向上扩展；空格后使用系统麦克风图标，长按期间保留按下反馈。松开自动结束并识别，上滑取消，不需要点击完成。

未开启会话、识别失败和超时也在同一区域显示说明，原键盘保持可见；不会自动切页面或打开主 App。首次授权和会话失效后仍需按原规则在主 App 手动开启音频会话。

10 项不同的专项界面测试均已有通过记录。竖屏、横屏和超会说中，空格、MNO、GHI、回车共 12 组矩形（位置和大小）实测位移为 0 pt；取消后的按键位置也在 1 pt 容差内通过。拼音组合中长按、连续两次长按、上滑取消、内部草稿、错误/空录音、未开启会话提示、收起键盘取消及原生跨 App 采集回填均已验证。普通中文、英文、数字、横屏输入回归通过。

结果按每项最后状态去重统计，分轮保留；初轮包含系统设置导航恢复及提示标题被手势移动覆盖的失败，已修正并补验。原生跨 App 测试使用真实麦克风与 WAV 转换，ASR 返回为测试服务；本轮没有新增真实模型准确率或实体 iPhone 验收。

Debug 模拟器与无签名 iOS arm64 Release 构建通过，Release 测试服务检查通过。当前用户模拟器已更新并启动，保留现有配置。
