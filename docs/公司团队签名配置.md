## 文件与构建

证书、私钥、描述文件、本机 Team 配置均留在本机，不纳入 Git。描述文件在本地“证书申请/2026-11-19”文件夹，也已复制到 Xcode 的描述文件目录。

自动签名未选用此次手动下载的配置，本次使用已下载的描述文件与本机有效开发身份完成手动签名。`config/Signing.xcconfig` 中配置公司 Team 及各 Target 对应的 profile 名称；该文件被 Git 忽略。

```sh
xcodebuild -project LianAiKeyboard.xcodeproj -scheme LianAiKeyboard \
  -configuration Release -destination 'generic/platform=iOS' \
  -derivedDataPath .build-artifacts/CompanySigning \
  CODE_SIGN_STYLE=Manual \
  CODE_SIGN_IDENTITY='本机对应开发证书的 SHA-1' \
  'PROVISIONING_PROFILE_SPECIFIER=$(LIANAI_PROFILE_$(TARGET_NAME))' build
```

这是 Development 配置，不是 Ad Hoc 或 App Store Connect 分发配置。
