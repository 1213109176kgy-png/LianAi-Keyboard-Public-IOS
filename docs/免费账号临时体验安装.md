日期：2026-11-04。

**最新体验包已更新为包含输入、音频阻塞及删空拼音修复的版本。朋友有 Windows 电脑时请先看[Windows 安装步骤](朋友Windows安装流程.md)。下方旧归档包保留作历史记录，不要发旧包代替最新版。**

## 能做到什么

没有付费开发者账号，也可以使用自己的免费 Apple 账号为自己的设备做开发签名和临时安装。免费签名七天到期，之后需要重新签名/安装；它不是可发链接给所有人直接安装的 Ad Hoc 或 TestFlight 分发。

本次提供的是 **iPhone 真机 arm64、Release、未做有效设备签名的 IPA 基础包**。它尚不是直接可安装包，不能把“打包成功”当作“已在免费账号真机验收通过”。后续已在本机免费账号完成主 App 与键盘扩展签名、真机安装和连续中文输入验证，见 [真机修复记录](真机底部占位与输入流畅度修复.md)。这不代表此历史 IPA 在其他账号/重签工具下已经验证。

## 推荐：先验证一台免费账号真机

1. 在 Mac 的 Xcode → Settings → Accounts 登录自己的免费 Apple 账号，账号和验证码直接在 Xcode 输入。
2. 打开 `LianAiKeyboard.xcodeproj`，为 `LianAiKeyboard` 和 `LianAiKeyboardExtension` 选择同一 Personal Team，启用自动签名。
3. 为该账号配置可用的主 App Bundle ID、扩展 Bundle ID、App Group 和 Keychain 共享组。若现有标识已被其他账号占用，需要使用该账号专用命名空间重新构建；不能只改主 App 的 Bundle ID。
4. 连接自己的 iPhone，完成信任配对和系统要求的开发者模式，选择手机运行。
5. 在手机添加恋爱键盘并开启完全访问，实际验证拼音上屏、AI 配置共享、粘贴回复，以及主 App 开启语音后在其他 App 长按空格。
6. 第一台验证通过后，再处理朋友各自账号的安装。免费 Personal Team 不是任意朋友设备的公开分发签名；每位朋友应使用自己的账号给自己的手机签名。

## 朋友有 Windows / Mac 电脑时的自签尝试

[Sideloadly 官方网站](https://sideloadly.io/)提供免费 Apple 账号导入 IPA、签名并安装的流程。一般步骤是连接 iPhone、信任电脑、导入本 IPA、使用自己的 Apple 账号签名，再按系统要求启用开发者模式及信任开发者。

但本项目与普通单体 App 不同：**必须保留键盘扩展，且主 App 与扩展的 App Group、Keychain 共享权限必须一致。** 工具如果仅重签主程序、移除扩展，或者改了共享组却没有同步客户端组名，会导致键盘缺失、配置不共享或语音无法使用。因此 Sideloadly 只是待验证的安装路径，当前不保证不同账号任意重签后功能完整。

若自签工具无法正确处理共享权限，采用前面的 Xcode 按账号配置、重新构建安装方式。不要把只成功打开主 App 当作键盘体验验收完成。

当前工程标识：

| 项目 | 值 |
| --- | --- |
| 主 App | `com.lianai.keyboard.ios` |
| 键盘扩展 | `com.lianai.keyboard.ios.Keyboard` |
| App Group | `group.com.lianai.keyboard` |
| Keychain 共享组 | `$(AppIdentifierPrefix)com.lianai.keyboard.shared` |

共享组名称还由 `LianAiCore.Product.group` 使用；给某个账号改名时，需要同步两份 entitlements 和客户端配置。

免费账号通常受七天签名有效期、最多三个已安装自签 App、App ID 数量等限制。续签使用相同账号和 Bundle ID，避免变成另一个独立 App。没有电脑的朋友，不能通过本次未签名 IPA 直接完成上述安装流程。
